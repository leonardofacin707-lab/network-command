Network Command

Você é um pacote de dados atravessando a rede. Cada nível é um dispositivo no caminho, do básico ao avançado.

Projeto de portfólio de Leonardo Facin, feito em JavaScript puro (sem frameworks).
Trilha baseada nos tópicos do curso Conceitos Básicos de Redes (Cisco Networking Academy); perguntas e explicações originais.
